# Sideline Sidekick

Your all-in-one coaching companion for tryout management, team building, and league tracking.

## Features

- **Tryout Manager** — Evaluate players, organize groups, and assemble final teams
- **League Results** — Import and browse past season standings by division
- **Playmaker** — *(coming soon)*
- **Squad Assist** — *(coming soon)*

## Tech Stack

- **Frontend:** React, TypeScript, Vite, TailwindCSS
- **Backend:** Express, SQLite

## Local Development

```bash
npm install
npm run dev
```

The app runs at `http://localhost:5173` with the API server on port `3000`.
