### Overview

Create a plan to use created training activities to create session plans.

In Playmaker, there should be a way to switch between activities and sessions.

Each session plan should be a combination of activities, and I should be able to export the session plan to a markdown file.

Each session plan should have

- The Game Phase of the Session (enforce the 4 phases or other)
- A Session Title
- An Overall Objective
- 1 Main Principle
- 1-2 Sub Principles
- 1-6 Activities linked to the session

I should be able to view all activities collapsed within a session by default, but then I can expand to see content and edit the content within the session.

Editing the content of an activity within a session should prompt me to either overwrite the activity, or save as a clone.

If I change the activity elsewhere, that change should reflect within the session when I return to it.
